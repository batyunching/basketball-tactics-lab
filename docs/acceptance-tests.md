## Phase 4 自動化測試

| 範圍 | 測試 | 數量 |
| --- | --- | --- |
| 規則偵測 | 傳切、擋拆＋協防、5v5 突破分球的召回／精確；±0.2 m 抖動；全員靜止無事件 | 13 |
| 證據不足 | 未確認球權／出手、未標記球權、低身分信心、位置缺漏 | 6 |
| 教材轉換 | 教材格式驗證、只用確認事件、教師修改內容進教材、不含追蹤原始資料、沒有確認事件時拒絕 | 6 |
| 合成基準 | 3 情境 × 5 個雜訊等級 × 20 種子；乾淨召回 1、σ ≤ 0.3 m F1 ≥ 0.85 | 3 |
| RLS 刪除 | 學生／其他教師不能刪作答；戰術不能硬刪（只能擁有者軟刪除）；刪任務連帶刪作答 | 4 |
| E2E（桌機＋觸控） | 未標球權時明確說無法確認 → 標記球權與出手 → 分析 → 修改並確認 → 補漏 → 重新整理後保留 → 轉教材 → 發布本機連結 → 另一台裝置學生作答答對 → 竄改連結被拒 → 刪除教材 → 刪除影片連帶刪除 AI 分析 | 2 |

全部：單元／元件／RLS 200 項、E2E 30 項（15 個情境 × 桌機＋觸控平板）。

## Phase 4 驗收對照

| 計畫書要求 | 驗證方式 |
| --- | --- |
| AI 繁中輸出六項內容 | 單元測試檢查每事件都有含數字的證據、中文推論與建議、信心；E2E 檢查卡片內容 |
| 證據不足明確說無法確認 | 單元測試 6 項＋E2E 未標球權情境 |
| 教師可編輯、確認後才進教材 | E2E 修改後重整仍保留、教材含修改文字；單元測試否決事件不進教材 |
| 學生互動教材 | E2E 學生在另一個瀏覽器環境開啟連結作答 |
| 權限與刪除 | RLS 刪除 4 項＋E2E 本機刪除清除 |
| 品質評估 | `docs/quality-evaluation.md`、編輯器內即時精確率／召回率 |
