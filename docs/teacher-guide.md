# 教師操作說明

## 畫面配置

- **上方**：戰術名稱、戰術檔、復原 ↶／重做 ↷、匯入、匯出 JSON、PNG、專注模式、全螢幕、儲存狀態。
- **左側**：人數（1v1～5v5）、半場／全場、換邊進攻、操作模式（移動球員／繪圖）、縮放、預設隊形。
- **中央**：球場。半場時進攻籃框固定在上方；全場時紅隊預設往右攻。
- **右側**：選取球員的屬性、球權與事件、戰術步驟與教師註解。
- **下方**：上一步、播放／暫停、下一步、時間軸、速度（0.25～2 倍）、循環。

## 常用操作

| 想做的事 | 做法 |
| --- | --- |
| 移動球員 | 「✋ 移動球員」模式下用滑鼠或手指拖曳。鍵盤方向鍵可微調選取的球員（Shift 加大）。 |
| 鎖定球員 | 點選球員 → 右側「🔒 鎖定位置」。鎖定後拖不動，避免上課誤觸。 |
| 改背號 | 點選球員 → 右側「背號」欄位（同隊不可重複）。 |
| 交球／傳球 | 把籃球拖到球員身上；同隊之間會記錄為「傳球」。或點選球員 → 「設為持球」「傳球給…」。 |
| 投籃、運球 | 點選持球者 → 「投籃」「運球」。投籃時球會飛向該隊進攻的籃框。 |
| 攻守轉換 | 右側「⇆ 攻守轉換」，球交給另一隊 1 號位。 |
| 畫戰術線 | 切到「✏️ 繪圖」→ 選跑動／傳球／運球／掩護／標註圈／防守色塊與顏色 → 在球場上拖曳。從球員身上開始畫會自動吸附到球員中心。 |
| 擦掉線條 | 繪圖模式選「橡皮擦」點線條；或「清除本步畫線」。 |
| 放大局部 | 左側 ＋／－、滑鼠滾輪或雙指縮放；放大後拖曳空白處可平移。 |
| 大屏幕講解 | 「全螢幕」或「專注」（隱藏兩側面板，球場最大）。 |

## 預設隊形

- 左側 **1～5 大按鈕** 一鍵套用前五組隊形（雙方位置、球權、方向、人數、半／全場一起還原）。
- 「保存目前站位」：按兩次確認，把目前球場存進該組。
- 「＋ 新增」：把目前站位存成新隊形（不限五組）；可改名、複製、刪除；「還原內建五組」可找回系統預設。
- 內建五組：3v3 基本三角、3v3 強弱邊、5v5 五外拉開、5v5 1-3-1 vs 2-3 區域、5v5 全場跳球。

## 做一段戰術動畫（例：站位 → 掩護 → 突破 → 空切 → 傳球 → 投籃）

1. 第 1 步排好起始站位（可先套用隊形），在「步驟名稱」輸入「站位」。
2. 按「＋ 新增步驟」：會複製目前位置成為第 2 步。拖曳球員到下一個位置，名稱打「掩護」，可畫掩護 T 字線。
3. 重複新增步驟。傳球、投籃要在「發生的那一步」操作（例如第 6 步點持球者 → 投籃）。
4. 每步可調「移動時間」與「教師註解」，註解會在球場左上方顯示給學生看。
5. 下方 ⏭「下一步」一次播一段；▶ 連續播放；速度選 0.5× 慢速講解；🔁 循環反覆示範。播放中按「✎ 回到編輯」即可修改。

## 儲存與帶走

- 每次修改 0.5 秒後自動存在**這台電腦的瀏覽器**（IndexedDB），重新整理或斷網後仍在。
- 「📁 戰術檔」可開新戰術、切換、刪除。
- 換電腦或備份：「匯出 JSON」→ 到另一台按「匯入」。匯入會成為新的戰術，不會覆蓋原本的。
- 「PNG」匯出目前球場圖片，可放進講義或簡報。
- 注意：清除瀏覽器資料會刪掉本機戰術，重要戰術請定期匯出 JSON。

## 快捷鍵

`Ctrl+Z` 復原、`Ctrl+Y`／`Ctrl+Shift+Z` 重做、`空白鍵` 播放／暫停、`Esc` 回到編輯並取消選取、方向鍵微調球員。

# Phase 2：教材庫、學生任務、雲端

上方選單：**🏀 戰術白板**｜**📚 教材庫**｜**👩‍🏫 學生任務**｜右上角 **☁ 雲端**。

## 教材庫

- 六套教材：傳切、擋拆、無球掩護、快攻（三打二）、人盯人與協防、2-3 區域防守輪轉。
- 「📖 動畫講解」：▶ 播放、⏭ 一次一步、點步驟可跳轉、速度與循環；下方顯示每一步的說明。適合直接上大屏幕講解。
- 三題互動練習：
  - **站位挑戰**：把黃色虛線圈的球員拖到合理位置。很多題有不只一個正確位置（例如側翼或底角都對）。
  - **跑位預測**：預測某位球員下一步去哪；答完會播放正確移動，並留下你的猜測位置做比較。
  - **戰術選擇**：單選或複選，複選題可能有多個合理答案，漏選給部分分。
- 「✎ 複製到白板修改」：在白板開一份副本自由修改，原教材不受影響。

## 發布任務給學生

1. 「學生任務」→ 選教材、輸入任務名稱、給學生的話、勾選題目 → **發布並產生連結**。
2. 把 QR Code 投影到大屏幕，學生用手機掃描；或複製連結貼到班級群組。
3. 學生填班級、座號、姓名 → 看動畫 → 作答（可重試，每題以最後一次計分）→ 繳交。
4. 「作答紀錄」：看每位學生總分、每題得分（綠＝全對、黃＝部分、紅＝錯）、點姓名看作答明細、寫回饋、匯出成績 CSV（Excel 可直接開）。

| | 雲端任務（已登入雲端） | 本機任務（未登入） |
| --- | --- | --- |
| 學生繳交 | 自動上傳 | 下載「作答結果」檔交給老師 |
| 老師收作業 | 自動出現在作答紀錄 | 「匯入學生結果檔」（可一次選多個檔） |
| 學生看回饋 | ✅ 任務頁「我的紀錄」 | ❌（回饋只存在老師電腦） |
| 關閉繳交 | ✅「關閉繳交」 | — |

學生端只有觀看與作答，沒有任何編輯教材的按鈕；雲端權限也在資料庫端限制學生不能修改教材。

## 雲端同步與衝突

- 登入教師帳號後，白板戰術會自動同步到雲端；換電腦登入同一帳號即可取得。
- 斷網時照常使用，右上角顯示「☁ 離線（N 待傳）」，連線後自動上傳。
- 同一份戰術在兩台裝置都被修改時，右上角變成「⚠ 衝突」，系統**不會自動覆蓋**，請選擇：保留這台的版本／改用雲端版本／兩份都保留。


# Phase 4：AI 戰術分析

在「🎥 影片分析」完成 ④ 身分校正或 ⑤ 人工關鍵影格後，切到 **⑦ AI 戰術分析**。

## 1. 確認球權與得分（一定要做）

系統**不追蹤球**，也不會自己判斷進球，所以要請老師標記：

1. 拖動時間軸到球換手的瞬間 → 選「持球者」→ **＋ 標記持球**。
2. 出手的瞬間 → 選「出手者」，勾或不勾「進球」→ **＋ 標記出手**。
3. 若在 ⑤ 關鍵影格已設定持球者，可按「從關鍵影格匯入持球者」，再逐筆勾「確認」。

沒勾「確認」的標記，相關事件會顯示「證據不足」。

## 2. 執行分析與審核

按 **🤖 執行 AI 戰術分析**。每張事件卡包含：

- **時間點**：可點選跳到影片該處。
- **相關球員**：附角色，例如掩護者、被擋的防守者。
- **可見證據**：位置、距離、速度等數字。
- **戰術推論**、**教學建議**。
- **信心**：高、中、低、證據不足。證據不足時會寫出原因。

審核方式：

- **✅ 確認**：AI 判斷正確。
- **❌ 否決**：AI 判斷錯誤。例如擋拆時「上前延阻」被判成協防。
- **✎ 修改**：改寫證據、推論、建議。證據不足的事件要先修改，才能確認。
- **＋ 新增 AI 漏掉的事件**：老師補充，也會用來計算 AI 的漏抓率。

「重新分析」會保留已審核的結果。下方的「品質評估」會顯示 AI 這次的精確率與召回率。

## 3. 轉成學生教材

輸入教材名稱 → **📚 轉成互動教材**。系統只使用「已確認」的事件，做成戰術動畫，並自動出題：

| 事件 | 自動出的題目 |
| --- | --- |
| 空切、突破 | 跑位預測 |
| 掩護 | 站位挑戰 |
| 傳球 | 傳給誰？ |
| 協防 | 誰該協防？ |
| 得分 | 這球為什麼能得分？（複選） |

教材會出現在「📚 教材庫 → 我的教材」，可以開啟、發布、刪除，發布方式和內建教材一樣：

- **本機連結**：教材內容壓縮在連結裡，學生手機不需要老師的電腦。連結被改動時，學生端會顯示無法驗證。
- **雲端任務**：學生自動上傳作答。

教材裡**不包含影片**與追蹤原始資料，只有球場上的位置與文字說明。刪除影片時，該影片的 AI 分析一併刪除；已轉出的教材保留，需要時可另外刪除。
