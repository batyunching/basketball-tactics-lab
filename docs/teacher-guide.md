# 教師操作說明

## 畫面配置

- **上方**：戰術名稱、戰術檔、復原 ↶／重做 ↷、匯入、匯出 JSON、PNG、專注模式、全螢幕、儲存狀態。
- **左側**：人數（1v1～5v5）、半場／全場、換邊進攻、操作模式（移動球員／繪圖）、縮放、預設隊形。
- **中央**：球場。半場時進攻籃框固定在上方；全場時紅隊預設往右攻。
- **右側**：選取球員的屬性、球權與事件、戰術步驟與教師註解。
- **下方**：上一步、播放／暫停、下一步、時間軸、速度（0.25～2 倍）、循環。

## 常用操作

| 想做的事 | 做法 |
| --- | --- |
| 移動球員 | 「✋ 移動球員」模式下用滑鼠或手指拖曳。鍵盤方向鍵可微調選取的球員（Shift 加大）。 |
| 鎖定球員 | 點選球員 → 右側「🔒 鎖定位置」。鎖定後拖不動，避免上課誤觸。 |
| 改背號 | 點選球員 → 右側「背號」欄位（同隊不可重複）。 |
| 交球／傳球 | 把籃球拖到球員身上；同隊之間會記錄為「傳球」。或點選球員 → 「設為持球」「傳球給…」。 |
| 投籃、運球 | 點選持球者 → 「投籃」「運球」。投籃時球會飛向該隊進攻的籃框。 |
| 攻守轉換 | 右側「⇆ 攻守轉換」，球交給另一隊 1 號位。 |
| 畫戰術線 | 切到「✏️ 繪圖」→ 選跑動／傳球／運球／掩護／標註圈／防守色塊與顏色 → 在球場上拖曳。從球員身上開始畫會自動吸附到球員中心。 |
| 擦掉線條 | 繪圖模式選「橡皮擦」點線條；或「清除本步畫線」。 |
| 放大局部 | 左側 ＋／－、滑鼠滾輪或雙指縮放；放大後拖曳空白處可平移。 |
| 大屏幕講解 | 「全螢幕」或「專注」（隱藏兩側面板，球場最大）。 |

## 預設隊形

- 左側 **1～5 大按鈕** 一鍵套用前五組隊形（雙方位置、球權、方向、人數、半／全場一起還原）。
- 「保存目前站位」：按兩次確認，把目前球場存進該組。
- 「＋ 新增」：把目前站位存成新隊形（不限五組）；可改名、複製、刪除；「還原內建五組」可找回系統預設。
- 內建五組：3v3 基本三角、3v3 強弱邊、5v5 五外拉開、5v5 1-3-1 vs 2-3 區域、5v5 全場跳球。

## 做一段戰術動畫（例：站位 → 掩護 → 突破 → 空切 → 傳球 → 投籃）

1. 第 1 步排好起始站位（可先套用隊形），在「步驟名稱」輸入「站位」。
2. 按「＋ 新增步驟」：會複製目前位置成為第 2 步。拖曳球員到下一個位置，名稱打「掩護」，可畫掩護 T 字線。
3. 重複新增步驟。傳球、投籃要在「發生的那一步」操作（例如第 6 步點持球者 → 投籃）。
4. 每步可調「移動時間」與「教師註解」，註解會在球場左上方顯示給學生看。
5. 下方 ⏭「下一步」一次播一段；▶ 連續播放；速度選 0.5× 慢速講解；🔁 循環反覆示範。播放中按「✎ 回到編輯」即可修改。

## 儲存與帶走

- 每次修改 0.5 秒後自動存在**這台電腦的瀏覽器**（IndexedDB），重新整理或斷網後仍在。
- 「📁 戰術檔」可開新戰術、切換、刪除。
- 換電腦或備份：「匯出 JSON」→ 到另一台按「匯入」。匯入會成為新的戰術，不會覆蓋原本的。
- 「PNG」匯出目前球場圖片，可放進講義或簡報。
- 注意：清除瀏覽器資料會刪掉本機戰術，重要戰術請定期匯出 JSON。

## 快捷鍵

`Ctrl+Z` 復原、`Ctrl+Y`／`Ctrl+Shift+Z` 重做、`空白鍵` 播放／暫停、`Esc` 回到編輯並取消選取、方向鍵微調球員。
