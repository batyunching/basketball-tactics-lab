| ID | 模組 | Phase 1 狀態 |
| --- | --- | --- |
| M01 | 球場引擎 | ✅ 半場（直向、籃框在上）／全場（橫向）、1v1～5v5、換邊進攻（整份戰術鏡射）、FIBA 28×15m 參數化標線、縮放（按鈕／滾輪／雙指）與平移、全螢幕、專注模式 |

| 儲存 | IndexedDB | ✅ 0.5 秒自動儲存、重新整理恢復、多份戰術檔、revision 遞增、離線快取（service worker） |
| 交換 | JSON | ✅ 匯出（戰術＋隊形）、匯入（zod 驗證、版本檢查、匯入為新專案）、PNG 匯出 |

| M08 | 學生挑戰 | ✅ 站位挑戰、跑位預測、戰術選擇；多個合理解（多判定區、多正確選項、部分分）；提示、重試、解說；教師回饋 |

| 雲端 | Supabase | ✅ Email 教師登入、學生匿名登入、戰術同步、任務、作答、回饋；未設定時完整的本機模式 |
| 同步 | 離線與衝突 | ✅ 離線佇列、operationId 冪等重送、修訂版 compare-and-swap、衝突三種處理、不靜默覆寫 |

## 尚未完成（依計畫屬後續階段，或本階段刻意不做）

- M09～M12：影片管理、視覺追蹤、同步對照、AI 解說（Phase 3～4）。
- 教師自行出題（題目編輯器）：目前題目來自六套內建教材；教師自己的戰術可發布為「觀看」用途需後續加入。
- 隊形（formations）尚未雲端同步，只存本機。
- 分數由學生端計算後上傳（教師可看作答明細核對），尚未在伺服器端重新評分。
- 雲端流程（登入、發布、繳交、回饋）的自動化測試以 RLS 測試＋同步引擎模擬測試涵蓋；真實 Supabase 的端對端測試需在設定完成後手動驗收。
- 步驟之間「事件時間點」目前固定在段落中段出手，尚不能逐事件調整時間。
- 戰術線不會隨球員移動而自動跟著走（線是畫在該步驟的固定位置）。
- 無「多選一起拖曳」與框選。
- 尚未做 PWA 安裝圖示的多尺寸 PNG（目前只有 SVG 圖示）。
- 未在實體觸控大屏幕／iPad 實機驗證，只用 Playwright 模擬觸控測試；建議上課前實機試一次。
