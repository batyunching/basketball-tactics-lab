# 需求與 Phase 1 完成狀態

| ID | 模組 | Phase 1 狀態 |
| --- | --- | --- |
| M01 | 球場引擎 | ✅ 半場（直向、籃框在上）／全場（橫向）、1v1～5v5、換邊進攻（整份戰術鏡射）、FIBA 28×15m 參數化標線、縮放（按鈕／滾輪／雙指）與平移、全螢幕、專注模式 |
| M02 | 球員互動 | ✅ 紅藍圓形編號、滑鼠＋觸控拖曳（Pointer Events）、選取、鎖定、座標約束（含界外 1m）、背號編輯（同隊唯一）、數值座標輸入、方向鍵微調、復原重做（拖曳合併為一筆） |
| M03 | 籃球與球權 | ✅ 指定持球者、球隨持球人移動、拖球交球／傳球、傳球／運球／投籃事件、攻守轉換、動畫中球的飛行（拋物線放大） |
| M04 | 教學畫筆 | ✅ 跑動實線、傳球虛線（終點吸附接球者）、運球波浪、掩護 T 字、標註圈、防守色塊、5 色、橡皮擦、清除本步 |
| M05 | 預設隊形 | ✅ 內建五組；保存雙方位置、球權、方向、人數、場地；新增／覆寫／改名／複製／刪除／還原內建，不限五組 |
| M06 | 動畫編輯器 | ✅ 多步驟、easeInOut 平滑插值、上／下一步、播放／暫停、時間軸拖曳、0.25～2 倍速、循環、步驟排序、移動時間、教師註解 |
| 儲存 | IndexedDB | ✅ 0.5 秒自動儲存、重新整理恢復、多份戰術檔、revision 遞增、離線快取（service worker） |
| 交換 | JSON | ✅ 匯出（戰術＋隊形）、匯入（zod 驗證、版本檢查、匯入為新專案）、PNG 匯出 |

## 尚未完成（依計畫屬後續階段，或本階段刻意不做）

- M07～M12：教材庫、學生挑戰、影片管理、視覺追蹤、同步對照、AI 解說（Phase 2～4）。
- 雲端同步與登入（Supabase）：已預留 `TacticRepository` 介面與 IndexedDB `syncQueue` 資料表，尚未接雲端。
- 學生唯讀分享連結與權限。
- 步驟之間「事件時間點」目前固定在段落中段出手，尚不能逐事件調整時間。
- 戰術線不會隨球員移動而自動跟著走（線是畫在該步驟的固定位置）。
- 無「多選一起拖曳」與框選。
- 尚未做 PWA 安裝圖示的多尺寸 PNG（目前只有 SVG 圖示）。
- 未在實體觸控大屏幕／iPad 實機驗證，只用 Playwright 模擬觸控測試；建議上課前實機試一次。
